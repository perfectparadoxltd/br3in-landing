BR3IN Documentation

Welcome to BR3IN — the decentralized P2P knowledge network for AI. This documentation covers everything you need to get started.

BR3IN is currently in v0.4.0-alpha. Some features may change before the stable release.

Installation

BR3IN is a desktop application built with Tauri (Rust + React). Download the installer for your operating system:

macOS

# Download .dmg from br3in.com/download
# Or via Homebrew (coming soon):
brew install --cask br3in

Windows

# Download .msi from br3in.com/download
# Run the installer and follow the prompts

Linux

# Download .AppImage from br3in.com/download
chmod +x BR3IN-*.AppImage
./BR3IN-*.AppImage

# Or via .deb:
sudo dpkg -i br3in_*.deb

From Source (Python backend)

git clone https://github.com/diegochavesta/BR3IN.git
cd BR3IN
pip install -e .
br3in serve  # Start the API on port 3939

Quick Start

After installation, BR3IN walks you through a 6-step onboarding wizard:

  • 1. Welcome — Introduction to BR3IN
  • 2. Name your Node — Give your node a name on the network
  • 3. Select a folder — Choose which folder to index
  • 4. Indexing — BR3IN processes your files into vector chunks
  • 5. Test search — Try a search to see it working
  • 6. Done! — Connected to the network

Your First Search

Once indexed, you can search your knowledge from the GUI, CLI, or API:

GUI

Open the app and type your query in the search bar. Results appear instantly from your local index and (if connected) the network.

CLI

$ br3in search "How does NAT traversal work in P2P?"

[1] Score: 0.89 — networking/nat-traversal.md
    "NAT traversal uses hole punching to establish direct..."

[2] Score: 0.76 — research/libp2p-notes.md
    "libp2p implements AutoNAT for reachability detection..."

REST API

curl -X POST http://localhost:3939/search \
  -H "Content-Type: application/json" \
  -d '{"query": "NAT traversal", "top_k": 5}'

Nodes

A Node is your local instance of BR3IN. Each Node has a unique cryptographic identity (Ed25519 keypair) that serves as its ID on the network. Your private key never leaves your device.

Nodes connect to each other forming a peer-to-peer network. When you search, your query can travel across the network to find knowledge stored on other nodes.

Collections

Collections are how you organize your indexed content. Each collection has a visibility level:

  • PRIVATE — Only you can see and search this content. Never leaves your device. Pro+
  • SHARED — Visible to specific nodes you choose. End-to-end encrypted. Pro+
  • PUBLIC — Visible to the entire network. Anyone can search it.

Important: BR3IN never shares your original files. Only processed text chunks (~512 tokens) are transmitted. Think of it like Google snippets, not file sharing.

The Network

The BR3IN network uses a custom protocol (BR3IN/1.0) over TCP with full encryption. Key components:

  • Kademlia DHT — Peer discovery and content routing
  • LAN Discovery — Automatic discovery of nodes on your local network
  • Relay Nodes — For nodes behind NAT/firewalls Pro+
  • Query Router — Smart routing that selects which nodes to query based on topic
  • Peer Exchange — Gossip protocol for sharing peer information

Privacy Model

BR3IN is built on the principle of OPT-IN sharing:

  • Your files never leave your device
  • Only you decide what to share (PRIVATE / SHARED / PUBLIC)
  • All network traffic is encrypted (AES-256-GCM + Noise Protocol)
  • Node identity uses Ed25519 — no passwords, no accounts on our servers
  • Enterprise tier adds homomorphic encryption — search without revealing your query

CLI Reference

br3in ingest <path>     # Index a file or directory
br3in search <query>    # Search your knowledge
br3in stats              # View index statistics
br3in serve              # Start the API server (port 3939)
br3in forget <path>     # Remove a file from the index
br3in --help             # Show all commands

REST API Team+

The REST API runs on http://localhost:3939 by default.

POST /search              # Search local + network
POST /ingest/file         # Index a single file
POST /ingest/directory    # Index a directory
GET  /stats               # Index statistics
GET  /health              # Health check
DELETE /forget             # Remove from index
POST /search/encrypted    # Homomorphic search (Enterprise)
GET  /analytics/*         # Analytics endpoints (Pro+)

MCP Server

BR3IN includes a Model Context Protocol server for integration with Claude, Cursor, VS Code, and other MCP-compatible tools.

# Start MCP server (stdio transport)
br3in-mcp

# Or:
python -m br3in.mcp.server

Available MCP tools: br3in_search, br3in_ingest_file, br3in_ingest_directory, br3in_stats, br3in_forget

OpenAI-Compatible API

BR3IN exposes an OpenAI-compatible endpoint so any LLM that supports the OpenAI API format can use BR3IN as a knowledge source.

# Point your LLM at BR3IN:
OPENAI_BASE_URL=http://localhost:3939/v1
OPENAI_API_KEY=br3in-local

Security

6-layer security architecture:

  • Layer 1: Original files never leave your device
  • Layer 2: AES-256-GCM encryption in transit (Noise Protocol)
  • Layer 3: Ed25519 cryptographic identity per node
  • Layer 4: Granular ACL per collection (PRIVATE/SHARED/PUBLIC)
  • Layer 5: X25519 ECDH key exchange with HKDF
  • Layer 6: Rate limiting per node

FAQ

Does BR3IN share my files?

No. Your original files never leave your device. BR3IN only transmits short text chunks (~512 tokens) when other nodes query your PUBLIC or SHARED collections. Think Google snippets, not file sharing.

Do I need an internet connection?

No. BR3IN works fully offline for local search. Internet is only needed to connect to the P2P network and search other nodes.

Which LLMs work with BR3IN?

All of them. BR3IN is LLM-agnostic. It provides context to any LLM via MCP (Claude, Cursor), OpenAI-compatible API (GPT, Llama, Mistral), or REST API.

Is BR3IN open source?

No. BR3IN is proprietary software owned by Perfect Paradox Ltd. The Free tier is free to use, but the source code is not open.

What happens if I cancel my subscription?

You keep access until the end of your billing period, then your account reverts to the Free tier. Your local data remains on your device. Private/Shared collections become inaccessible on the network until you resubscribe.
